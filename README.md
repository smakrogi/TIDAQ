TIDAQ
=====
Tissue Identification and Quantification Tool

<img width="1916" height="1003" alt="image" src="https://github.com/user-attachments/assets/af087c28-a9bc-472f-b78e-9e3e079c2435" />

Software tool for segmentation and quantification of lower leg pQCT and mid-thigh CT scans.
Github project: http://smakrogi.github.io/TIDAQ/
Tutorial videos with TIDAQ instructions: https://www.youtube.com/channel/UCgFYk8fnZkBkWbUHykMwupg
Windows installation package is under the "Install" directory

If you use this method please cite:
S. Makrogiannis, Boukari, F., and Ferrucci, L., “Automated skeletal tissue quantification in the lower leg using peripheral quantitative computed tomography”, Physiological Measurement, vol. 39, p. 035011, 2018.
