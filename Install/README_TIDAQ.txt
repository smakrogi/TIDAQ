INSTALLATION INSTRUCTIONS (FOR WINDOWS PLATFORM)
1. (Optional) Please install Microsoft Visual C++ 2008 SP1 Redistributable Package (x86), if not already installed 
              (English version in http://www.microsoft.com/download/en/details.aspx?id=5582)

2. Download mipav from https://mipav.cit.nih.gov/download.php. Please download the 32bit MIPAV version, not the 64bit version. 
   Install mipav using installMIPAV.exe. Please leave default selections during installation.

3. Unzip TIDAQ_v1-4.zip to your local drive. The package includes:

	Documentation
	* User's documentation in TIDAQ_Documentation.pdf

	TIDAQ installation Files: 
	* PlugInTIDAQ.jar and PlugInTibestResources.exe
	* Please refer to the first section in user's documentation on installation and TIDAQ 1 Installation Demo. It is simple as it takes two steps. 
	  First install the jar file plugin through mipav and then run PlugInTibestResources.exe to install required dll and other resources.

4. View the tutorial videos with the main steps from installation to usage on 'https://www.youtube.com/channel/UCgFYk8fnZkBkWbUHykMwupg/videos'. 
   I suggest viewing the videos following the number order to understand the basic operations in the application.

5. Software should be ready to use. Please view the demos and then see the documentation files for more details.

IMPORTANT NOTE
Our recommendation is to download the files, browse videos and user's guide, and install mipav and TIDAQ plugin. 
If you encounter difficulties please contact me by email to smakrogiannis@desu.edu.
